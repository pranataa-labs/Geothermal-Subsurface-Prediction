Model Specifications & Geophysical Screening Scope
Model Architecture (Optuna TPE Optimized)

This system predicts the 5-depth subsurface temperature profile (1000m–5000m) as a machine learning surrogate using a Multi-Output Hybrid Stacking Ensemble:

  • Random Forest Regressor: 100 Decision Trees (max_depth: 20).
  • XGBoost Regressor: 300 Boosting Trees (max_depth: 10, learning_rate: 0.1733).
  • Meta-Learner: Depth-specific Multiple Linear Regression trained on 3-Fold Out-of-Fold (OOF) predictions and evaluated under 5-Fold Cross-Validation and Spatial Block Cross-Validation.
Preliminary Thermal Screening Scope

This application serves as a preliminary regional thermal screening tool based on public crustal and upper-mantle seismic velocity and gravity models across the Conterminous US. Site-specific drilling decisions require complementary local hydrogeological, permeability, and exploratory borehole assessments.
